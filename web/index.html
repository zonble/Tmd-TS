/* 演奏流程宣告與轉調 */
-> intro -> verse -> {?+1} -> verse ->#
  • 1–7：簡譜音階；^：高八度；_：低八度。
  • [1], [6m], [Cmaj7]：和弦標記。
  • (1 2 3)%(--)：連音符（三連音等）。
  • {!= 140}, {?+2}：動態速度與轉調指令。
