TMD 簡明語法速查

          
        

        

          
TMD (Timebase Mark Down) 是阿怪設計的純文字音樂標記語言，支援多音軌簡譜、和弦與播放流導出。

          
::SCORE::
** 曲名 (Title) **
!= 120              /* 速度 BPM */
?= C                /* 調號 Key */
<4/4>               /* 拍號 Meter */

/* 段落:樂器@|小節偏移|{ ... } */
intro:Piano@|0|{
  <2*>              /* 1 小節 2 拍 */
  |[1] - | [6m] - |
}

verse:Lead@|0|{
  <4*>              /* 1 小節 4 拍 */
  | 1 2 3 1 | 5 - 3 - |
}

/* 演奏流程宣告與轉調 */
-> intro -> verse -> {?+1} -> verse ->#

          
    
            
  • 1–7：簡譜音階；^：高八度；_：低八度。
    • 
            
  • [1], [6m], [Cmaj7]：和弦標記。
    • 
            
  • (1 2 3)%(--)：連音符（三連音等）。
    • 
            
  • {!= 140}, {?+2}：動態速度與轉調指令。
    • 
          

        

        

          
        

      

      
      
        

          
TMD 與 AI 協作作曲指南

          
        

        

          
          

            
步驟 1：取得 TMD Skill 並載入 AI 技能庫

            

              TMD 是結構化純文字音樂語言。將 TMD Skill 載入至您的 AI 工具（Claude Code、Codex、Antigravity、Gemini、Cursor 等），AI 即可精確遵循簡譜、和弦標記、軌道小節位移與轉調規範：
            

            

              
              
            


            

              
或於終端機一鍵全域安裝至本機各 AI 技能目錄：

              

                npx tmd-ts --install-skills
                
              

            


            

              
各工具常見 Skill 目錄（將下載的 SKILL.md 放入即可）：

              
    
                
  • Claude Code: ~/.claude/skills/tmd/SKILL.md
    • 
                
  • Codex: ~/.codex/skills/tmd/SKILL.md
    • 
                
  • Gemini / Antigravity: ~/.gemini/config/skills/tmd/SKILL.md
    • 
                
  • Cursor / VS Code: .cursor/rules/tmd.md / 專案根目錄 AGENTS.md
    • 
              

            

          


          
          

            
步驟 2：AI 協同作曲實戰 5 大心法

            

              不同於無法細修的黑箱音樂生成，在 TMD 中人與 AI 就像「結對程式設計（Pair Programming）」一般互動協作：
            


            

              
              

                
1. 旋律配器編排（Lead-to-Arrangement）

                
人類寫好主旋律（Vocal），請 AI 加上木吉他伴奏、貝斯走音與鼓組進場。

                
Prompt 範例：「這是我用 TMD 寫的主旋律，請為它編排伴奏：加入 CHORD 軌彈奏吉他和弦、Bass 軌彈奏根音，並在第 2 小節以 @|+2| 讓鼓組 Drums 進場。」

              


              
              

                
2. 動機延伸與問答樂句（Motif Continuation）

                
提供 2 到 4 小節核心旋律動機，請 AI 依據問句（Antecedent）與答句（Consequent）發展成完整 8 小節樂段。

                
Prompt 範例：「這是一段 2 小節動機：1 2 3 5 | 6 5 3 -。請幫我依古典樂問答樂句結構，發展成完整 8 小節段落，並在第 8 小節收束在主音 1。」

              


              
              

                
3. 和弦風格探索與重配（Re-Harmonization）

                
TMD 的和弦是一等公民（如 [1]、[6m]、[Cmaj7]、[Am7]），可隨時請 AI 嘗試標準流行進行或 Neo-Soul / 爵士副屬和弦重配。

                
Prompt 範例：「請針對這段旋律提出兩種不同風格的 TMD 和弦進行：1. 標準流行樂 1-5-6-4；2. 帶有次屬和弦與調式互換的 Neo-Soul / 爵士和弦。」

              


              
              

                
4. 動態織度與段落進場（Textural Build-Up）

                
善用 TMD 的小節位移語法 @|0|、@|+4| 與弱起過門 @|-1|，指揮 AI 安排樂器逐層堆疊與退場，營造豐富的起承轉合。

                
Prompt 範例：「第 1 段主歌只留木吉他；第 4 小節加入貝斯；在副歌前 1 小節以 @|-1| 讓鼓組進行過門（Fill-in），隨後副歌全體齊奏進場。」

              


              
              

                
5. 巨觀曲式流程與轉調（Macro Flow & Modulation）

                
段落各自獨立完成後，由 AI 在 -> 播放順序中規劃重複與轉調（如最後一次副歌升半音 {?+1}）。

                
Prompt 範例：「我已經寫好了 intro、verse、chorus、bridge，請幫我規劃 TMD 的 -> 演奏順序，並在最後一段副歌加入升半音轉調 {?+1}。」
